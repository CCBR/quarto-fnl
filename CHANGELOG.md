## quarto-fnl 1.0.0

Themes for Quarto using FNL branding guidelines!
This repository provides two theme extensions:

- `fnl`: light and dark themes for HTML and revealjs formats.
- `fnl-report`: light theme specifically for analysis reports in HTML formats.

View the documentation website for more details on usage and customization:
<https://ccbr.github.io/quarto-fnl/>
